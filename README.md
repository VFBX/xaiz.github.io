# XAIZ SCRIPT — Bản tĩnh VIP

Đây là bản tĩnh VIP của website XAIZ SCRIPT, chạy được ngay trên GitHub Pages tại https://vfbx.github.io/

## Đây là bản nào?

- Giao diện giống bản chính VIP PRO MAX: avatar mèo, nền aurora, AI Hub, thẻ kính mờ, Spotlight, thẻ script có LINK VƯỢT / LINK CHÍNH / LINK PHỤ / SAO CHÉP LINK, khung GHI CHÚ, phân trang, nhạc "Nơi Này Có Anh", Hộp Quà, AI Chat.
- Đây là **bản tĩnh** (1 file `index.html` duy nhất), không phải bản chính fullstack.

## Giới hạn quan trọng

- **Bản chính fullstack có máy chủ không chạy trên GitHub Pages.** Bản chính có kho lưu bài đăng, kiểm tra mật khẩu ở máy chủ và AI Chat chạy ở máy chủ — những phần đó không chạy được trên Pages (chỉ host tĩnh). Muốn dùng đầy đủ thì dùng bản chính trong Muse.
- **Bài đăng chỉ lưu trên máy người mở trang** (localStorage). Người khác mở trang riêng sẽ không thấy bài của bạn.
- **Mật khẩu Admin chỉ lưu dạng mã băm SHA-256** trong file, không có mật khẩu gốc trong code. Admin mở ẩn bằng cách bấm 3 lần avatar mèo, hoặc gõ mật khẩu vào ô tìm kiếm.
- **AI Chat trong bản này chỉ trả lời mẫu / tạo script mẫu**, không nối với AI thật và không có API key trong file.

Mở https://vfbx.github.io/ bằng trình duyệt trên điện thoại hoặc máy tính là dùng được ngay, không cần cài gì thêm.
